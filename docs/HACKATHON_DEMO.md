# GABA — NextStep Hacks Guided Demo

This flow is designed for a sub-5-minute judge demo.

## Demo sequence

1. Open `/#platform`.
2. Select **Hackathon Demo**.
3. GABA establishes a normal baseline, then injects a deterministic leak pattern.
4. Within ~2 seconds, the anomaly engine correlates elevated night flow, falling downstream pressure and reservoir drawdown.
5. Open the generated **AI Environmental Intelligence** brief.
6. Review evidence, confidence, predicted impact and the human-control boundary.
7. Select **Approve & create inspection**.
8. Open inspection `WO-031`.
9. Select **Verify repair complete**.
10. GABA returns the simulated network to baseline and shows the impact result.

## Judge-visible outcome

The final Command Centre displays:

- projected avoided loss: **2.34 ML/day**
- restored night-flow baseline: **22.4 L/s**
- restored downstream pressure baseline: **421 kPa**
- demo response time: **23 min**
- resolved alert state
- field evidence and post-intervention audit events

The 2.34 ML/day figure is explicitly labelled as a **demo projection**, derived from the simulated 2,340 m³/day detected loss rate. It is not presented as a measured real-world saving.

## Governance point

The AI does not isolate valves or execute consequential infrastructure controls. It detects, explains and recommends. A human operator approves the inspection, and a field actor verifies the repair before the system records the outcome.
